步驟一：輸入 GAS Web App URL

請輸入您的 Google Apps Script Web App 部署網址，此網址將用於所有後端資料操作。

步驟二：選擇 Google 試算表

請從您的 Google Drive 中選擇一份試算表。

步驟三：選擇工作表

請選擇試算表中的工作表分頁，系統將讀取第一列作為欄位標題。

步驟四：設定表單欄位

為每一個欄位設定問題類型、問題標題、是否必填，以及（如適用）選項內容。
