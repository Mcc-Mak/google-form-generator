# 使用者故事 (User Stories)

本文件以使用者故事格式描述每個精靈步驟的需求，並附驗收條件。

## US-01：設定 GAS Web App URL

**身為**需要建立 Google 表單的使用者，  
**我想要**輸入 GAS Web App 的部署網址，  
**以便**前端能與後端通訊完成表單建立流程。

### 驗收條件

- [x] AC-01-1：頁面顯示 URL 輸入框，placeholder 為 `https://script.google.com/macros/s/.../exec`
- [x] AC-01-2：URL 為空時點擊「下一步」顯示錯誤訊息「請輸入 GAS Web App URL。」
- [x] AC-01-3：URL 格式無效時顯示錯誤訊息「請輸入有效的網址格式。」
- [x] AC-01-4：點擊「儲存網址」將 URL 存入 `localStorage`，顯示成功訊息
- [x] AC-01-5：頁面載入時自動從 `localStorage` 讀取已儲存的 URL 並填入輸入框

## US-02：選擇 Google 試算表

**身為**需要從試算表建立表單的使用者，  
**我想要**從 Google Drive 中選擇一份試算表，  
**以便**系統讀取其工作表與欄位標題。

### 驗收條件

- [x] AC-02-1：進入步驟二時自動呼叫 `listSpreadsheets` 載入試算表清單
- [x] AC-02-2：下拉式選單顯示所有試算表，每個選項的 value 為試算表 ID、文字為檔案名稱
- [x] AC-02-3：清單載入中時下拉式選單顯示「載入中…」並停用
- [x] AC-02-4：未選擇試算表時點擊「下一步」顯示錯誤訊息「請選擇一份試算表。」
- [x] AC-02-5：點擊「重新載入」按鈕可重新取得試算表清單
- [x] AC-02-6：Google Drive 中無試算表時顯示「找不到任何試算表」

## US-03：選擇工作表

**身為**已選擇試算表的使用者，  
**我想要**選擇試算表中的工作表分頁，  
**以便**系統讀取該工作表第一列的欄位標題。

### 驗收條件

- [x] AC-03-1：進入步驟三時自動呼叫 `listSheets` 載入工作表清單
- [x] AC-03-2：下拉式選單顯示所有工作表分頁名稱
- [x] AC-03-3：未選擇工作表時點擊「下一步」顯示錯誤訊息「請選擇一個工作表分頁。」
- [x] AC-03-4：點擊「重新載入」按鈕可重新取得工作表清單
- [x] AC-03-5：試算表中無工作表時顯示「找不到任何工作表」

## US-04：設定表單欄位

**身為**已選擇工作表的使用者，  
**我想要**為每個欄位設定問題類型、問題標題、是否必填及選項，  
**以便**系統依據設定建立 Google 表單。

### 驗收條件

- [x] AC-04-1：進入步驟四時自動呼叫 `getHeaders` 載入欄位標題
- [x] AC-04-2：每個欄位顯示為一張卡片，包含欄位編號與原始標題
- [x] AC-04-3：每張卡片提供問題類型下拉式選單，包含 8 種類型
- [x] AC-04-4：問題標題輸入框預設填入試算表欄位標題
- [x] AC-04-5：必填核取方塊預設為未勾選
- [x] AC-04-6：選擇「單選」「核取方塊」「下拉式清單」時顯示選項編輯器（textarea，每行一個選項）
- [x] AC-04-7：選擇其他類型時隱藏選項編輯器
- [x] AC-04-8：任一欄位的問題標題為空時點擊「下一步」顯示錯誤訊息
- [x] AC-04-9：點擊「重新載入欄位」按鈕可重新取得欄位標題

## US-05：選擇目標資料夾與表單資訊

**身為**已設定欄位的使用者，  
**我想要**選擇表單儲存的資料夾並輸入表單標題與說明，  
**以便**表單建立後儲存至正確位置。

### 驗收條件

- [x] AC-05-1：進入步驟五時自動呼叫 `listFolders` 載入資料夾清單
- [x] AC-05-2：下拉式選單顯示所有資料夾，value 為資料夾 ID、文字為資料夾名稱
- [x] AC-05-3：表單標題輸入框預設填入所選試算表名稱
- [x] AC-05-4：未選擇資料夾時點擊「下一步」顯示錯誤訊息「請選擇目標資料夾。」
- [x] AC-05-5：未輸入表單標題時點擊「下一步」顯示錯誤訊息「請輸入表單標題。」
- [x] AC-05-6：表單說明為選填欄位
- [x] AC-05-7：Google Drive 根目錄無資料夾時顯示「找不到任何資料夾」

## US-06：顯示結果

**身為**已完成所有設定的使用者，  
**我想要**系統自動建立表單並顯示連結，  
**以便**我能前往編輯或發布表單。

### 驗收條件

- [x] AC-06-1：進入步驟六時自動呼叫 `createForm` 建立表單
- [x] AC-06-2：建立過程中顯示「正在建立表單，請稍候…」載入訊息
- [x] AC-06-3：建立成功後顯示編輯連結 (Edit URL) 與發布連結 (Published URL)
- [x] AC-06-4：每個連結旁提供「複製」按鈕，點擊後複製連結至剪貼簿
- [x] AC-06-5：複製成功後按鈕文字暫時變為「已複製！」，2 秒後恢復
- [x] AC-06-6：建立失敗時顯示錯誤訊息
- [x] AC-06-7：點擊「重新開始」按鈕重置所有狀態並回到步驟一

## US-07：步驟導覽

**身為**使用精靈的使用者，  
**我想要**在步驟之間自由切換，  
**以便**修改先前的設定。

### 驗收條件

- [x] AC-07-1：每個步驟提供「上一步」與「下一步」按鈕
- [x] AC-07-2：步驟指示器顯示目前步驟（高亮）與已完成步驟
- [x] AC-07-3：點擊已完成的步驟指示器可跳轉至該步驟
- [x] AC-07-4：切換試算表時重置工作表、欄位與表單欄位狀態
- [x] AC-07-5：切換工作表時重置欄位與表單欄位狀態
