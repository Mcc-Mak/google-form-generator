# 專案章程 (Project Charter)

## 1. 專案名稱

Google 表單建立精靈 — 從 Google 試算表自動產生 Google 表單

## 2. 專案目標

提供一個直覺的網頁精靈，讓使用者能從現有的 Google 試算表標題列自動建立 Google 表單，並將表單儲存至指定的 Google Drive 資料夾。具體目標如下：

1. **降低手動建立表單的成本**：使用者無需逐一在 Google Forms 中建立問題，直接從試算表標題列批次產生。
2. **確保資料安全**：所有 Google API 呼叫皆透過 GAS 後端代理，前端不暴露任何 API 金鑰或憑證。
3. **支援多種問題類型**：提供 8 種問題類型（簡答、段落、單選、核取方塊、下拉式清單、線性刻度、日期、時間），涵蓋常見表單需求。
4. **零外部相依**：前端使用純 Vanilla JS，不依賴任何 CDN 或第三方套件。

## 3. 專案範圍

### 3.1 包含範圍 (In Scope)

| 項目 | 說明 |
|---|---|
| 前端精靈 UI | 6 步驟精靈流程，包含 GAS URL 輸入、試算表選擇、工作表選擇、欄位設定、資料夾與表單資訊、結果顯示。 |
| GAS 後端 | 5 個 action 端點：`listSpreadsheets`、`listSheets`、`getHeaders`、`listFolders`、`createForm`。 |
| 表單建立 | 根據試算表標題列自動產生 Google 表單，支援 8 種問題類型，並可移動至指定 Drive 資料夾。 |
| 部署 | 前端部署至 GitHub Pages，後端透過 clasp 部署至 Google Apps Script。 |

### 3.2 不包含範圍 (Out of Scope)

| 項目 | 說明 |
|---|---|
| 使用者認證系統 | 本專案依賴 GAS 的 `ANYONE_ANONYMOOUS` 存取設定，不實作獨立認證。 |
| 表單回覆管理 | 不提供表單回覆的查看、匯出或分析功能。 |
| 多語系支援 | 僅支援繁體中文介面。 |
| 離線運作 | 需要網路連線才能與 GAS 後端通訊。 |
| 表單編輯 | 已建立的表單不支援透過本工具重新編輯。 |

## 4. 利害關係人

| 角色 | 身份 | 關注重點 |
|---|---|---|
| 產品負責人 | 需要批次建立表單的團隊主管 | 操作效率、正確性 |
| 一般使用者 | 行政人員、問卷設計者 | 介面易用性、步驟清晰度 |
| 開發者 | 維護本專案的工程師 | 程式碼品質、部署流程、安全性 |
| IT 管理員 | 管理 Google Workspace 的 IT 人員 | GAS 權限設定、資料夾存取控制 |
| 安全審查者 | 負責資安審查的人員 | 前端無敏感資訊、GAS 權限最小化 |

## 5. 成功標準

| 編號 | 標準 | 驗證方式 |
|---|---|---|
| S1 | 使用者能在 6 個步驟內完成表單建立 | 手動測試完整精靈流程 |
| S2 | 所有 Google API 呼叫皆經由 GAS 後端，前端不含任何 API 金鑰 | 程式碼審查 |
| S3 | 支援 8 種問題類型且每種類型皆能正確建立對應的表單項目 | 各類型逐一測試 |
| S4 | 前端不依賴任何 CDN 或外部資源 | 檢查 HTML/CSS/JS 無外部引用 |
| S5 | GAS 後端回傳格式一致為 `{ ok, data?, error? }` | API 回應格式驗證 |
| S6 | 前端能正確處理後端錯誤並顯示繁體中文錯誤訊息 | 錯誤情境測試 |
| S7 | 表單建立後能正確移動至使用者選擇的 Drive 資料夾 | 建立後驗證資料夾位置 |
| S8 | 介面所有文字均為繁體中文 | UI 介面審查 |

## 7. 風險

| 風險 | 影響 | 緩解措施 |
|---|---|---|
| GAS `ANYONE_ANONYMOUS` 存取設定導致未授權存取 | 高 | 限制 GAS 專案的 OAuth 範圍，僅授予必要權限；建議在內部環境使用。 |
| 試算表標題列含空白欄位導致表單問題異常 | 中 | 前端在步驟四驗證所有欄位標題非空。 |
| Drive 根目錄無資料夾導致無法建立表單 | 中 | 前端顯示明確錯誤訊息，引導使用者先建立資料夾。 |
